# 十、人资部功能要点

> 人资部管理员工全生命周期：档案、考勤、招聘、工资、人事变动。

```mermaid
flowchart TD
    subgraph 入职链路
        A["🏢 公司信息"] --> B["📋 招聘管理<br/>用人申请→招聘计划→面试"]
        B --> C["📚 培训管理"]
        C --> D["📁 人资档案"]
    end

    D --> E["🔐 系统账号<br/>自动生成→管理员激活→权限分配"]

    subgraph 在职管理
        D --> F["⏰ 考勤管理<br/>班次→班组→排班→存档"]
        F --> G["💰 工资管理<br/>工资项目→账套→存档→工资表"]
        G --> H["💰 工资发放"]
        H --> I["📊 财务成本归集"]

        D --> J["📊 绩效考核"]
        D --> K["📜 人事制度"]
    end

    subgraph 人事变动
        D --> L["🔄 人事调动"]
        L --> M["✅ 员工转正<br/>试用→正式"]
        L --> N["📋 员工调动"]
        L --> O["⚠️ 离职申请"]
        O --> P["🔴 离职确认<br/>状态: 正常→离职申请→离职"]
    end

    style D fill:#E8734A,color:#fff
    style E fill:#9B59B6,color:#fff
    style G fill:#D9534F,color:#fff
    style H fill:#D9534F,color:#fff
    style P fill:#D9534F,color:#fff
```
