# 速易联ERP — 权限分配矩阵

> 按角色梳理各模块的功能权限与数据权限范围。
> 权限分三级：✅ 完全操作 / 🔐 审批管理 / 👁️ 仅查看
> 搭配 [[13-上线准备手册#1.3 ⭐ 配置账号权限|权限模板配置]] 使用。

---

## 📋 角色定义

| 角色 | 说明 | 典型人员 |
|:----:|------|----------|
| **总经理** | 公司最高管理者，全局监控+审批决策 | 总经理 |
| **部门主管** | 本部门业务管理+审批，可查看本部门全部数据 | 各部门经理/主管 |
| **部门员工** | 本部门日常操作，仅操作自己负责的数据 | 各部门专员/员工 |
| **管理员** | 系统配置、基础数据维护、权限分配 | IT/系统管理员 |
| **库管** | 跨部门出入库操作，专注仓储 | 仓库管理员 |

## 🛡️ 系统管理（管理员专属）

| 功能 | 管理员 | 说明 |
|------|:------:|------|
| 组织架构管理 | ✅ | 建立部门/岗位层级 |
| 账号管理（激活/停用） | ✅ | 员工档案→系统账号 |
| 权限模板管理 | ✅ | 创建/编辑权限模板 |
| 权限分配 | ✅ | 为账号应用权限模板 |
| 基础数据维护 | ✅ | 产品分类、仓库分类等 |
| 项目流程配置 | ✅ | 定义项目阶段和模板 |
| 审批流程配置 | ✅ | 各模块审批节点设置 |
| 系统参数设置 | ✅ | 编号规则、预警值等 |

> [!warning] 管理员权限原则
> - 管理员**不参与**日常业务操作（不录入订单、不审批合同）
> - 管理员职责 = 系统配置 + 基础数据维护 + 权限分配
> - 如需参与业务，应为该员工**单独创建业务账号**，避免混用

| ⚙️ 系统设置 | 👁️ 可查看，不建议直接修改 |

## 🔑 部门主管 vs 部门员工权限差异速查

| 对比维度 | 部门主管 | 部门员工 |
|----------|----------|----------|
| **数据范围** | 本部门全部 | 仅本人负责 |
| **审批权限** | 本模块关键节点审批 | 无审批权限 |
| **配置权限** | 可编辑模板/流程 | 仅使用，不配置 |
| **查看范围** | 本部门所有单据 | 仅自己创建的单据 |
| **报表权限** | 本部门统计报表 | 个人数据报表 |
| **跨部门操作** | 转出单据到其他部门（如合同转生产） | 同左（操作级别相同） |
| **删除/作废** | 可作废本人+本部门单据 | 仅可作废本人单据 |

## ⚠️ 权限配置注意事项

### 数据权限范围

> 速易联ERP权限 = **功能权限** + **权限范围**

| 权限范围 | 说明 | 适用角色 |
|----------|------|----------|
| 全部数据 | 可查看/操作公司所有数据 | 总经理、管理员 |
| 本部门数据 | 仅本部门数据 | 部门主管 |
| 本人数据 | 仅自己创建的数据 | 部门员工 |
| 指定部门 | 可访问特定部门的数据 | 跨部门协作角色（如库管） |

### 关键配置原则

1. **最小权限原则**：员工仅授予工作所需的最低权限
2. **审批分离**：创建人和审批人不能是同一人
3. **数据隔离**：销售员工之间互不可见客户和报价
4. **跨部门只读**：员工可查看其他部门信息但不可编辑
5. **财务双审**：付款和报销建议设置**主管+总经理**两级审批
6. **库管跨部门**：库管需要**跨部门数据权限**，能接收各部门出入库申请

### 审批流程建议

| 业务类型 | 建议审批链 | 说明 |
|----------|------------|------|
| 销售报价 | 销售员工 → 销售主管 → 总经理（大额） | 可按金额设置阈值 |
| 销售合同 | 销售员工 → 销售主管 → 总经理 | 合同必须审批 |
| 采购单 | 采购员工 → 采购主管 → 总经理（大额） | 按金额阈值区分 |
| 付款申请 | 采购/部门 → 财务主管 → 总经理 | 财务把关 |
| 费用报销 | 员工 → 部门主管 → 财务主管 | 两级审批 |
| 工资发放 | 人资制作 → 人资主管 → 总经理 | 工资敏感数据 |
| 退货审批 | 销售员工 → 销售主管 → 总经理 | 退货涉及成本 |
| 出库审批 | 销售员工 → 销售主管 | 常规可简化 |
| 会议室申请 | 员工 → 行政/主管 | 轻量审批 |

### 步骤

```
1. 进入「系统设置 → 权限模板管理」
```
