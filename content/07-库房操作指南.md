# 七、库房功能要点

> 库房管理是物资流转的枢纽，统一管理入库/出库/盘点/调拨等。

```mermaid
flowchart TD
    subgraph 入库来源
        A1["🛒 采购入库"]
        A2["🏭 生产入库"]
        A3["↩️ 退货入库"]
        A4["📦 委外入库"]
    end

    A1 & A2 & A3 & A4 --> B["📥 待入库单"]
    B --> C["✅ 确认入库"]

    C --> D["📊 库存数据"]

    D --> E["📤 待出库单"]
    E --> F["✅ 确认出库"]

    F --> G["🚚 发货作业"]

    D --> H["📋 库存盘点<br/>汇总盘点/精确盘点"]
    D --> I["🔄 库存调拨<br/>汇总移库/精确移库"]
    D --> J["🔧 组装/拆装"]
    D --> K["📦 借货/还货"]

    D -->|库存低于下限| L["⚠️ 库存预警"]
    L --> M["🛒 转预购"]

    style B fill:#E8734A,color:#fff
    style C fill:#5CB85C,color:#fff
    style D fill:#4A90D9,color:#fff
    style E fill:#E8734A,color:#fff
    style F fill:#5CB85C,color:#fff
    style G fill:#5CB85C,color:#fff
    style L fill:#D9534F,color:#fff
```
