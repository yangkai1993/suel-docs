# 九、售后部功能要点

> 售后部负责售后服务流程管理和维修处理。

```mermaid
flowchart TD
    A["📞 客户报修"] --> B["📋 售后流程配置"]
    B --> C["📝 受理单添加"]
    C --> D["🔧 售后维修处理"]
    D --> E{维修结果}
    E -->|维修完成| F["✅ 维修完成"]
    E -->|需换件| G["📦 配件出库"]
    G --> D
    E -->|需退货| H["↩️ 销售退货"]
    H --> I["🔄 销售换货"]

    NOTE["⚠️ 仅销售出库完成的产品<br/>才能进行售后维修"] -.-> D

    style A fill:#4A90D9,color:#fff
    style B fill:#4A90D9,color:#fff
    style C fill:#E8734A,color:#fff
    style D fill:#D9534F,color:#fff
    style F fill:#5CB85C,color:#fff
    style NOTE fill:#BDC3C7,color:#333,stroke-dasharray: 5 5
```
